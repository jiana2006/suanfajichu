    常用函数：

    其实我本来是想写在stl容器那里面的，但是考虑到这个函数的常用性，所以我决定重新弄了一个专门的页面来存放这些函数。

    sort：

    这个就不过多介绍了我之前在排序中已经介绍了。

    reverse：

    这个也比较常见，用于反转一个容器中的元素。

    例子：

    string s = "hello";
reverse(s.begin(), s.end()); // 变成 "olleh"

    unique：

    这个函数用于删除一个容器中重复的元素。

    例子：


    vector<int> v = {1,2,2,3,4,4,5};
v.erase(unique(v.begin(), v.end()), v.end()); // 变成 {1,2,3,4,5}

    lower_bound,upper_bound：

    这两个函数用于查找一个容器中第一个大于等于某个值的元素和第一个大于某个值的元素。 是的他们都是找大于某个数

    例子：

    vector<int> v = {1,2,3,4,5,6,7,8,9};
int l = *lower_bound(v.begin(), v.end(), 5); // 5
int u = *upper_bound(v.begin(), v.end(), 5); // 6

    max_element(),min_element()

    这两个函数用于查找一个容器中最大值和最小值的迭代器。


    因为这两个函数返回的是迭代器，所以我们需要用*来解引用。

    例子：


    vector<int> v = {1,2,3,4,5,6,7,8,9};
int max = *max_element(v.begin(), v.end()); // 9
int min = *min_element(v.begin(), v.end()); // 1

    _builtin_popcount()

    这个函数用于统计一个二进制数中1的个数。

    例子：

    int n = 5; // 101
int popcount = __builtin_popcount(n); // 2

    accumulate：

    这个函数用于计算一个容器中所有元素的和。


    例子：

    vector<int> v = {1,2,3,4,5};
int sum = accumulate(v.begin(), v.end(), 0); // 15

    nth_element：

    这个函数用于将一个容器中的元素按升序排序，但是只排序到第n个元素。

    例子：

    vector<int> v = {1,2,3,4,5};
nth_element(v.begin(), v.begin()+2, v.end()); // 变成 {1,2,3,4,5}

    iota：

    这个函数用于将一个容器中的元素按顺序赋值。

    例子：

    vector<int> v = {5,4,3,2,1};
iota(v.begin(), v.end(), 1); // 变成 {1,2,3,4,5}

    prev_permutation：

    这个函数用于生成一个容器中所有可能的排列。也就是我们常说的全排列。

    例子：

    vector<int> v = {1,2,3,4,5};
while(prev_permutation(v.begin(), v.end())){
    cout<<v[0]<<endl;
}

    next_permutation：

    这个函数用于生成一个容器中所有可能的排列。也就是我们常说的全排列。

    没错他和prev_permutation是相反的。一个是生成上一个排列，一个是生成下一个排列。

    例子：

    比如说123
    用next_permutation生成下一个排列是132->213->231->312->321
    而用prev_permutation生成上一个排列是321->231->213->132->123

    stio()/stoll()：

    这两个函数用于将一个字符串转换为一个整数。

    例子：

    string s = "123";
int n = stoi(s); // 123

    to_string()：

    这个函数用于将一个整数转换为一个字符串。

    例子：

    int n = 123;
string s = to_string(n); // "123"

    substr()：

    这个函数用于截取子字符串。

    例子：

    string s = "hello";
string sub = s.substr(1,3); // "ell"

    gcd(),lcm()：

    这两个函数用于计算两个整数的最大公约数和最小公倍数。

    例子：

    int a = 12;
int b = 16;
int g = __gcd(a,b); // 4
int l = a*b/g; // 48

    解释一下什么是lambda表达式：

    lambda表达式是一种匿名函数，可以在代码中直接定义和使用。
    他其实就是一个“就地定义好的、不用起名字的小函数”。
    我们来看一下他和普通函数的区别：

    普通函数：

    普通函数需要在代码中先定义，然后在需要使用的地方调用。

    例子：

    int add(int a, int b) {   // 定义一个函数，名字叫 add
    return a + b;
}

int main() {
    cout << add(2, 3);    // 调用
}

    lambda表达式：

    lambda表达式可以在代码中直接定义和使用，不需要在代码中先定义。

    例子：

    int main() {
    auto add = [](int a, int b) {   // 就地定义一个小函数
        return a + b;
    };

    cout << add(2, 3);              // 像函数一样调用
}

    我们来认识一下他的基本组成：

    auto multiply = [&](int a, int b) {……};
      变量名     捕获    参数

    部分              作用                       例子
[] 捕获列表     决定能用外面哪些变量      [&] 用外面所有变量
() 参数列表     像普通函数的参数                 (int x)
{} 函数体      具体做什么                        { ... }
    其中捕获列表可以是重点
    这是lambda和普通函数的区别 现在我们假设外面有变量： 
    int a = 10;
int b = 20;


    写法              含义
[]           什么都不捕获，用不了外面的 a、b
[&]          按引用捕获外面所有变量，能改 a、b
[=]          按值捕获外面所有变量，只能读，改不了原变量
[a]          只按值捕获 a
[&a]         只按引用捕获 a
[a, &b]      按值捕获 a，按引用捕获 b

    我们来写一道全排列的题目：

    全排列：

    输入一个整数n，输出1到n的全排列。
    题目保证0<n<=10。

    这个时候我们可以用next_permutation函数来实现。

    #include<bits/stdc++.h>
using namespace std;

int main(){
    int n;
    cin >> n;
    vector<int> v(n);
    iota(v.begin(), v.end(), 1);
    do {
        for(int i = 0; i < n; i++){
            cout << v[i];
        }
        cout << endl;
    } while(next_permutation(v.begin(), v.end()));

    return 0;
}
