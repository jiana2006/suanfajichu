    图

    我们来看一下如何建图：

    方法1：数组建图

    比如说我们要表示这样一个图： 1->3 ， 2->4， 3->2 我们就可以建立一个4*4的矩阵，来表示这个图。 矩阵的第i行第j列的元素为1，表示从i到j有一条边。 矩阵的第i行第j列的元素为0，表示从i到j没有边。 

     1 2 3 4
1[][][1][]
2[][][][1]
3[][1][][]
4[][][][]
    这个是无权图。 如果我们遇到有权图，我们就可以在矩阵中存储边的权重。 也就是数组中加数组，来存储边的权重。 我们本来是这样表示无权图的： 
    vector<vector<int>> graph(4, vector<int>(4, 0));
    现在有全图我们这样表示： 
    vector<vector<int[]>>graph(4, vector<int[]>());

    图论基础：图的存储 + BFS / DFS 遍历

    > 目标：能独立建图、写出 BFS/DFS 模板、算连通块、求无权最短路，并避开常见坑。

    一、图的两种存法

    设点数 n、边数 m（无向图存边时 m 要乘 2）。

    1. 邻接矩阵 g[n][n]

    g[u][v] = w;   // 有边记权值，无边记 INF / 0
    | 项目 | 说明 | |---|---| | 空间 | O(n²)，n ≤ 1000 左右还行，n = 1e5 直接爆 | | 查边 (u,v) | O(1) | | 遍历 u 的邻居 | O(n) | | 适用 | 稠密图、需要频繁判两点是否相邻、Floyd 类算法 |

    2. 邻接表 vector<vector<int>> g(n)

    g[u].push_back(v);          // 无向图再加 g[v].push_back(u)
    | 项目 | 说明 | |---|---| | 空间 | O(n + m)，稀疏图首选 | | 查边 (u,v) | O(deg(u))，一般够用 | | 遍历 u 的邻居 | O(deg(u))，BFS/DFS 靠这个才快 | | 适用 | 绝大多数题（BFS/DFS/最短路/拓扑排序） | 结论：默认用邻接表；只有稠密图或要 O(1) 判边时才用矩阵。

    C++ 进阶：边带权且要反复建图时用「链式前向星」（head[] + to[] + w[] + nxt[]），缓存友好；平时 vector<vector<pair<int,int>>> 就够。

    二、BFS（广度优先搜索）

    核心：队列 + 按层扩展

    关键细节：入队时就标记 visited，不是出队时。否则同一个点会被多个邻居重复入队，复杂度退化。

    C++ 模板（求无权最短路）

    #include <bits/stdc++.h>
using namespace std;
vector<int> bfs(int s, const vector<vector<int>>& g) {
    int n = g.size();
    vector<int> dist(n, -1);      // -1 = 未访问，同时当 visited 用
    queue<int> q;
    dist[s] = 0;                  // 入队即标记
    q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (dist[v] != -1) continue;   // 已访问
            dist[v] = dist[u] + 1;         // 无权图：层数 = 最短距离
            q.push(v);
        }
    }
    return dist;
}

    Python 模板

    from collections import deque
def bfs(s, g):
    n = len(g)
    dist = [-1] * n
    dist[s] = 0
    q = deque([s])
    while q:
        u = q.popleft()
        for v in g[u]:
            if dist[v] != -1:
                continue
            dist[v] = dist[u] + 1
            q.append(v)
    return dist

    性质与用途

    • 复杂度 O(n + m)（矩阵存图是 O(n²)）。
    • 只适用于边权相同（通常为 1）的图：第一次到达就是最短。
    • 队列里天然是「距离非降」的，所以可以按层处理（多源 BFS、层序输出）。
    • 用途：无权最短路、连通块、二分图判定（按层染色）、多源扩散（如 01 矩阵）、0-1 BFS（边权只有 0/1 时改用双端队列 deque）。

    多源 BFS 骨架

    queue<int> q;
for (int s : sources) { dist[s] = 0; q.push(s); }
// 之后和普通 BFS 一模一样

    三、DFS（深度优先搜索）

    核心：一条路走到黑，走不通回溯

    C++ 递归模板

    vector<int> vis(n, 0);
function<void(int)> dfs = [&](int u) {
    vis[u] = 1;                      // 进来就标记
    for (int v : g[u]) {
        if (!vis[v]) dfs(v);
    }
};

    显式栈版本（防爆栈）

    vector<int> vis(n, 0);
stack<int> st;
st.push(s);
while (!st.empty()) {
    int u = st.top(); st.pop();
    if (vis[u]) continue;            // 出栈时判重
    vis[u] = 1;
    for (int v : g[u]) if (!vis[v]) st.push(v);
}

    注意：显式栈的访问顺序和递归版不一样（邻居是反序压栈），如果题目要求按字典序输出遍历序列，用递归 + 邻接表排序更省事。

    用途

    • 连通块计数、判连通。
    • 有向图判环：三色标记（0 未访问 / 1 在栈上 / 2 已完成），遇到「在栈上」的点就是环。
    • 拓扑排序：DFS 后序取反。
    • 割点、桥、强连通分量（Tarjan）的地基。
    • 回溯搜索（排列组合、N 皇后、数独）—— DFS 的另一副面孔。

    复杂度

    O(n + m)；递归深度最坏 O(n)，n = 1e5 的链状图容易爆栈，改显式栈或加 #pragma / 迭代。

    四、BFS vs DFS 对比

    维度 BFS DFS
    数据结构 队列 queue 栈 / 递归
    扩展方式 一层一层 一条路到底
    空间 最坏 O(n)（宽图队列大） 最坏 O(n)（深图递归深）
    最短路 无权图可以 不行（不保证最短）
    环检测 可以（记录父节点） 可以（三色）
    典型场景 最短路、层序、多源扩散 连通块、拓扑、Tarjan、回溯
    都能做：遍历全图、判连通、数连通块。
    只能 BFS：无权最短路。
    只能 DFS：需要回溯 / 后序信息的（拓扑、强连通）。

    ## 五、六个必踩的坑
    1. 图不连通：只从 1 个点出发遍历不到全图，要外层 for (i = 1..n) if (!vis[i]) ...。
    2. visited 标记时机：BFS 入队即标，DFS 进函数即标；拖到出队/返回才标会重复入队甚至死循环。
    3. 无向图建边：两个方向都要 push；有向图只 push 一个方向，别顺手写成双向。
    4. 重边与自环：对 BFS/DFS 结果无影响（visited 会挡掉），但算度数、判环、最短路时要留意。
    5. 邻接表多组数据要清空：for (auto& e : g) e.clear(); 或重新 assign(n+1, {})。
    6. 递归爆栈：深链图 n = 2e5 用递归 DFS 会 RE，换显式栈。

    1 -- 2 -- 4

    1: 2 3
