<h2>内联函数</h2>
内联函数是一种特殊的函数，它的定义在函数调用的附近，编译器会自动将函数的代码插入到调用点，而不是调用函数。

我们使用inline关键字来定义内联函数。也称为内嵌函数。
引入内联函数是为了消除函数调用时的系统开销，提高程序的执行效率。

格式如下：
```
inline 返回值类型 函数名(参数列表){
    函数体;
}
```
比如下面的例子：

```cpp title="内联函数"
#include <iostream>
using namespace std;
inline int max(int a, int b){
    return a>b?a:b;
}
int main(){
    cout << max(1,2) << endl;
    return 0;
}
```

<h2>重载函数</h2>
重载函数是指在同一个作用域中，函数名相同，但参数列表不同的多个函数。编译器会根据函数调用时传入的参数类型和数量来决定调用哪个函数。

重载函数据有：
1.相同的函数名
2.不同的参数列表或者数据类型对应的顺序。

如：
```
int sum(int a, int b)//2个参数
int sum(int a, int b, int c)//3个参数
```
如：
```
float cube(float i)
int cube(int i)
```
如：
```
double sum(int a, double b)
double sum(double a, int b)
```
<b>注意：</b>

（1）若两个函数除了返回类型不同，其他都相同，那么非法。

如：
```
float cube(float i)
double cube(float i)//非法
```

(2)重载与带缺值的函数一起使用时，有可能会导致二义性。
如：
```
int sum(int a)
int sum(int a = 0, int b = 0, int c = 0)
```


下面我们学习：异常处理机制。

(1)检查异常（使用try语句块）

(2)抛出异常（使用throw语句）

(3)捕捉异常（使用catch语句）

一般格式如下：
```
throw 表达式;

try{
    可能会抛出异常的代码;
}catch(异常类型 异常对象){
    处理异常的代码;
}
```
