# Markdown 常用语法速查表

Markdown 是一种轻量级标记语言，常用于 GitHub、Typora、Obsidian、个人博客、README 文档和学习笔记。

## 1. 标题

使用 `#` 表示标题，最多支持六级标题。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 2. 文字格式

| 效果 | Markdown 语法 | 显示效果 |
|---|---|---|
| 粗体 | `**粗体文字**` | **粗体文字** |
| 斜体 | `*斜体文字*` | *斜体文字* |
| 粗斜体 | `***粗斜体***` | ***粗斜体*** |
| 删除线 | `~~删除文字~~` | ~~删除文字~~ |
| 行内代码 | `` `cout` `` | `cout` |
| 下划线（部分编辑器支持） | `<u>下划线</u>` | <u>下划线</u> |

## 3. 列表

### 3.1 无序列表

```markdown
- 苹果
- 香蕉
- 橘子
```

### 3.2 有序列表

```markdown
1. 第一步
2. 第二步
3. 第三步
```

### 3.3 嵌套列表

```markdown
- 编程语言
  - C++
  - Python
  - Java
- 前端技术
  - HTML
  - CSS
```

## 4. 链接和图片

### 4.1 超链接

```markdown
[百度](https://www.baidu.com)
```

### 4.2 插入图片

```markdown
![图片描述](图片地址)
```

### 4.3 设置图片大小（部分 Markdown 编辑器支持 HTML）

```html
<img src="图片地址" width="300">
```

## 5. 代码

### 5.1 行内代码

```markdown
使用 `cout` 输出内容。
```

### 5.2 多行代码块

在三个反引号后指定语言，可以获得语法高亮效果。

````markdown
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!";
    return 0;
}
```
````

常见语言标识：

| 语言 | 标识 |
|---|---|
| C++ | `cpp` |
| C | `c` |
| Python | `python` |
| Java | `java` |
| JavaScript | `javascript` |
| HTML | `html` |
| CSS | `css` |
| SQL | `sql` |
| Shell | `bash` |

## 6. 引用

使用 `>` 表示引用，可以通过增加 `>` 实现嵌套引用。

```markdown
> 这是一段引用文字。
>
> > 这是第二层引用。
> >
> > > 这是第三层引用。
```

## 7. 表格

```markdown
| 姓名 | 年龄 | 专业 |
|---|---|---|
| 张三 | 20 | 计算机 |
| 李四 | 21 | 电子科学 |
| 王五 | 19 | 软件工程 |
```

### 7.1 表格对齐

```markdown
| 左对齐 | 居中 | 右对齐 |
|:---|:---:|---:|
| 内容 | 内容 | 内容 |
```

说明：`:` 放在分隔线左侧表示左对齐，两侧都有 `:` 表示居中，放在右侧表示右对齐。

## 8. 分割线

以下写法都可以创建分割线：

```markdown
---
```

或

```markdown
***
```

## 9. 任务清单

```markdown
- [ ] 尚未完成的任务
- [x] 已完成的任务
```

## 10. 特殊符号

| 用途 | 写法 | 显示效果 |
|---|---|---|
| 不间断空格 | `&nbsp;` | `&nbsp;` |
| 小于号 | `&lt;` | &lt; |
| 大于号 | `&gt;` | &gt; |
| 版权符号 | `&copy;` | &copy; |
| 注册商标 | `&reg;` | &reg; |
| 乘号 | `&times;` | &times; |
| 除号 | `&divide;` | &divide; |

提示：Markdown 换行规则因编辑器而异。常见做法是在行末添加两个空格，或在两行之间空一行。

## 11. 常用转义

如果想显示 Markdown 中具有特殊含义的符号，可以在符号前添加反斜杠 `\`。

```markdown
\*这段文字不会变成斜体\*
\# 这行不会被识别为标题
\`反引号\`
```

常见可转义符号：`\`、`` ` ``、`*`、`_`、`{}`、`[]`、`()`、`#`、`+`、`-`、`.`、`!`、`|`。

## 12. 数学公式（部分 Markdown 编辑器支持）

行内公式：

```markdown
勾股定理：$a^2+b^2=c^2$
```

独立公式：

```markdown
$$
E = mc^2
$$
```

## 13. 实用模板：算法题解

````markdown
# 题目标题

## 一、题目描述

简要整理题目要求。

## 二、解题思路

说明核心观察、算法选择和实现步骤。

## 三、算法分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 四、代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cout << "Hello World!" << '\\n';
    return 0;
}
```

## 五、样例分析

| 输入 | 输出 | 说明 |
|---|---|---|
| 示例输入 | 示例输出 | 简要解释 |

## 六、总结

记录本题涉及的知识点、易错点和可以改进的地方。
````
