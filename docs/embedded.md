# 🤖 嵌入式开发

!!! abstract "什么是嵌入式？"
    嵌入式系统就是“被嵌入到某个设备中的专用计算机系统”。小到智能手环、微波炉，大到汽车电子、工业机器人、甚至航天器，里面都跑着嵌入式软件。
    一句话总结：**让代码真正动起来，去控制物理世界！**

---

## 🧠 嵌入式核心三要素

学习嵌入式，你主要是在和这三样东西打交道：

| 核心要素 | 说明 | 常见代表 |
| :--- | :--- | :--- |
| **MCU (微控制器)** | 也就是单片机，是整个系统的“大脑” | STM32、ESP32、51单片机 |
| **C/C++ 语言** | 嵌入式开发的绝对主力，需要极度关注内存与底层 | 指针、位操作、结构体 |
| **RTOS (实时操作系统)** | 当单片机任务太多，需要“调度”时使用 | FreeRTOS、RT-Thread、uCOS |
