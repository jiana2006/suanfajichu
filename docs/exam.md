# 🎓 考研指南：计算机科学与技术方向

!!! abstract "什么是考研？"
    考研是指考取研究生的考试。对于计算机科学与技术类的学生来说，考研是提升专业深度、进入更高平台的重要途径。

## 🧭 主要考研方向

我们计算科学与技术类学生考研的主要方向是**计算机方向**，通常分为以下几个主流细分领域：

- **计算机科学与技术（学硕）**：侧重理论与学术研究，适合未来想读博或进科研院所的同学。
- **软件工程（专硕/学硕）**：侧重工程实践与软件开发，就业面极广，是很多同学的首选。
- **人工智能 / 大数据**：目前最热门的交叉方向，对数学和算法要求较高。
- **网络空间安全**：偏向底层安全、密码学与网络攻防，国家需求量大。

## 📚 考试科目构成

一般考研分为**初试**和**复试**。初试通常考四门：

| 科目 | 说明 | 难度提示 |
| :--- | :--- | :--- |
| **政治 (101)** | 全国统考，背诵内容较多 | ⭐⭐ |
| **英语 (201/204)** | 学硕考英语一，专硕多考英语二 | ⭐⭐⭐⭐ |
| **数学 (301/302)** | 学硕考数一，专硕考数二 | ⭐⭐⭐⭐⭐ |
| **专业课 (408/自命题)** | 408统考含数据结构、计组、操作系统、网络 | ⭐⭐⭐⭐⭐ |

!!! tip "关于 408 统考"
    408 是计算机考研中最硬核的专业课。如果目标院校考 408，建议尽早开始复习，战线拉长，因为知识点极其密集。

## 🗓️ 备考时间线建议

=== "基础阶段 (3月 - 6月)"
    - **数学**：过完一轮教材，掌握基础概念，做基础题。
    - **英语**：每天背单词，长难句分析，做早年真题阅读。
    - **专业课**：确定学校，开始看数据结构等核心教材。

=== "强化阶段 (7月 - 9月)"
    - **数学**：强化复习，刷 1000 题，建立错题本。
    - **政治**：可以开始听网课，刷选择题。
    - **专业课**：二轮复习，做历年真题，总结题型。

=== "冲刺阶段 (10月 - 12月)"
    - **全科**：真题模拟，查漏补缺，背政治大题，保持心态平稳。
