    字符串

    我本来都不知道字符串属于算法，但是还是有许多字符串的题我遇到了还是不怎么能完全写对，因此我觉得还是很有必要的。

    首先我们先了解一下什么是字符串：像"hello"、"world"、"niukexinsheng"等，这些字符串都是由多个字符组成的序列。这些字符可以是字母、数字、标点符号等。

    字符串的长度可以是0，也可以是任意大的整数。像“12345789”也是一个字符串。

    字符串的每个字符都可以被访问到，也可以被修改。

    因此字符串用单独的string类来表示。

    我们再来了解一下基础的字符串操作：

    字符串的一些操作

    1.截取与获取

    substr()函数： substr()函数用于截取字符串的子串。

    语法： substr(int pos, int len)

    参数： pos：子串的起始位置。 len：子串的长度。

    返回值： 子串。

    2.查找

    find()函数： find()函数用于查找字符串中子串的第一个位置。

    语法： find(string str)

    参数： str：要查找的子串。

    返回值： 子串的第一个位置。

    3.修改和插入

    s.push_back()函数： s.push_back()函数用于在字符串的末尾添加一个字符。

    语法： s.push_back(char c)

    参数： c：要添加的字符。

    返回值： 无。

    s.insert()函数： s.insert()函数用于在字符串的指定位置插入一个字符。

    语法： s.insert(int pos, char c)

    参数： pos：插入位置。 c：要插入的字符。

    返回值： 无。

    s.erase()函数： s.erase()函数用于删除字符串的指定位置的字符。

    语法： s.erase(int pos)

    参数： pos：删除位置。

    返回值： 无。

    s.replace()函数： s.replace()函数用于替换字符串的指定位置的字符。

    语法： s.replace(int pos, int len, string str)

    参数： pos：替换位置。 len：要删除的字符的长度。 str：要插入的字符。

    返回值： 无。

    4.拼接与转换

    s1 += s2; //s1拼接s2 to_string()函数： to_string()函数用于将整数转换为字符串。

    语法： to_string(int n)

    参数： n：要转换的整数。

    返回值： 转换后的字符串。

    stoi()函数： stoi()函数用于将字符串转换为整数。

    语法： stoi(string str)

    参数： str：要转换的字符串。

    返回值： 转换后的整数。

    s.c_str()函数： s.c_str()函数用于将字符串转换为C风格的字符串。

    语法： s.c_str()

    参数： 无。

    返回值： 转换后的C风格的字符串。

    5.排序与反转

    sort()函数： sort()函数用于对字符串中的字符进行排序。

    语法： sort()

    参数： 无。

    返回值： 无。

    reverse()函数： reverse()函数用于将字符串中的字符反转。

    语法： reverse()

    参数： 无。

    返回值： 无。

    6.输入

    string s;

    cin>>s; getline(cin,s); cin.get();这三者的区别：

    cin>>s; 会自动跳过空格，直到遇到非空格字符。

    getline(cin,s); 会读取整行，包括空格。

    cin.get(); 会读取单个字符，包括空格。

    这里我们介绍一下cin.ignore();

    cin.ignore() 会忽略掉cin.get()读取的空格。

    我们先来几道简单题：

    6翻了：

    “666”是一种网络用语，大概是表示某人很厉害、我们很佩服的意思。最近又衍生出另一个数字“9”，意思是“6翻了”，实在太厉害的意思。如果你以为这就是厉害的最高境界，那就错啦 —— 目前的最高境界是数字“27”，因为这是 3 个 “9”！

    本题就请你编写程序，将那些过时的、只会用一连串“6666……6”表达仰慕的句子，翻译成最新的高级表达。

    输入格式：

    输入在一行中给出一句话，即一个非空字符串，由不超过 1000 个英文字母、数字和空格组成，以回车结束。

    输出格式：

    从左到右扫描输入的句子：如果句子中有超过 3 个连续的 6，则将这串连续的 6 替换成 9；但如果有超过 9 个连续的 6，则将这串连续的 6 替换成 27。其他内容不受影响，原样输出。

    6翻了.cpp
    #include<bits/stdc++.h>
using namespace std;

int main() {
    string s;
    // 【关键】用 getline 读入一整行，包含空格
    getline(cin, s); 

    int n = s.length();

    // 注意：这里的 i 没有写 i++，因为遇到连续的 6 时，i 会在内部自己增加
    for (int i = 0; i < n; ) {
        if (s[i] == '6') {
            int c = 0; // c 用来记录连续 6 的个数

            // 只要还是 6，就一直往后数
            while (i < n && s[i] == '6') {
                c++;
                i++;
            }

            // 数完之后，根据数量 c 输出
            if (c <= 3) {
                // 原样输出 c 个 6
                for (int j = 0; j < c; j++) {
                    cout << '6';
                }
            } else if (c <= 9) {
                cout << '9';
            } else {
                cout << "27";
            }
        } else {
            // 如果当前不是 6，原样输出，并且 i 往后走一步
            cout << s[i];
            i++;
        }
    }

    cout << "\n";
    return 0;
}
